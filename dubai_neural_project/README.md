# Нейросетевые модели оценки недвижимости и устойчивость к шуму

Завершённый учебный проект по нейронным сетям для магистратуры. Все таблицы и графики получены выполнением кода на предоставленном `off_plan.csv`. Исходные файлы сохранены. Основной отчёт — `report/project_report.docx`; обоснование решений — `report/decision_log.md`; тезисы и ответы для защиты — `report/defense_notes.md`.

## Что получено

Сравнены медианный ориентир, Ridge, Random Forest, LightGBM, MLP и TabResNet. Для каждого подхода проверены `ln(P)` и `ln(P/A)` на одних и тех же строках, где P — полная цена USD, A — площадь м². Качество обеих постановок оценивается по полной цене в USD.

Временное разделение: 6 738 объектов 2021–2023 для обучения, 2 278 объектов 2024 для настроек и ранней остановки, 2 984 объекта 2025–апреля 2026 для теста. Выбор архитектуры, настроек и цели выполняется по validation MAE; основной seed 42 зафиксирован заранее.

| Выбранная модель | Цель | Test MAE USD | Test MAPE | Test R² |
|---|---|---:|---:|---:|
| LightGBM | P/A | 139 891 | 7,38% | 0,9812 |
| Random Forest | P/A | 164 765 | 8,51% | 0,9730 |
| TabResNet | P | 415 240 | 30,86% | 0,9062 |
| MLP | P/A | 534 781 | 34,98% | 0,8649 |

Эта таблица показывает один заранее заданный seed. Для обеих целей MLP и TabResNet выполнены также seeds 43 и 44. Например, MAE TabResNet на P по трём seed — 491 785 ± 66 833 USD (среднее ± SD). Лучший seed по тесту не выбирался. На отдельном разбиении с исключением проектов TabResNet лучше LightGBM; оно проверяет новый проект при смешанных датах, поэтому не заменяет временной результат.

Набор рассматривается как учебный с предполагаемым синтетическим происхождением. В 4 600 записях объявление предшествует году запуска проекта, в 66 передача предшествует запуску. Объединённое правило исключает 4 611 строк. Отдельная проверка с таким исключением переобучает модели; её результаты сохранены. Реальность сделок, механизм генерации и доступность всех атрибутов в момент объявления по исходным CSV не подтверждены. Полученная точность не является гарантией для действительного рынка Дубая.

## Быстрый просмотр

Откройте `project.ipynb`: в нём уже есть таблицы, графики и результаты выполненных ячеек. Полное обучение по умолчанию выключено. Ячейки последовательно проверены в IPython; стандартные ячейки Python совместимы с Jupyter. Для просмотра самого отчёта Python не требуется.

`original/` содержит прежний notebook и markdown-отчёт без изменений. Их метрики относятся к старому протоколу. Актуальные числа находятся в `outputs/` и новом отчёте.

## Установка и повторный запуск

Проверенная среда: Linux, Python 3.12.14, CPU. GPU не требуется. Версии основных библиотек зафиксированы в `requirements.txt`; фактическая среда — в `outputs/environment.json` и `outputs/runtime_versions.json`.

Запускайте команды из каталога `dubai_neural_project`:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
export OPENBLAS_NUM_THREADS=2
export OMP_NUM_THREADS=2
export MKL_NUM_THREADS=2
python -m unittest discover -s tests -v
python src/verify_results.py
```

Проверки сохранённых результатов не переобучают модели. Полный пересчёт:

```bash
python src/experiment.py --stage all
python src/plots.py
python src/verify_results.py
```

Он заново строит все модели, 32 кандидата подбора, дополнительные нейросетевые seed, 540 оценок входных искажений, 45 переобучений с повреждёнными ценами и дополнительные диагностические опыты. Время зависит от CPU. Результаты Ridge, Random Forest и LightGBM воспроизводятся точно; у нейросетей на другой платформе или версии PyTorch MAE может отличаться на несколько процентов (при повторной проверке на Windows с PyTorch 2.7.1 TabResNet дала 429 866 вместо 415 240 USD), что согласуется с разбросом по seed в отчёте. Результаты по умолчанию заменяют `outputs/`; для независимого повторного эксперимента используйте `--out outputs_repeat`.

Этапы при необходимости запускаются последовательно:

```bash
python src/experiment.py --stage tune
python src/experiment.py --stage evaluate
python src/experiment.py --stage robustness
python src/experiment.py --stage diagnostics
python src/experiment.py --stage sensitivity
```

`tune` создаёт `selection_frozen.json` до вычисления нового тестового сравнения. Следующие этапы требуют этот файл и обученные модели. Этап `robustness` требует завершённый `evaluate`, поскольку использует повторные seed нейросетей.

Для ноутбука:

```bash
python -m pip install -r requirements-notebook.txt
jupyter notebook project.ipynb
```

Если Jupyter Notebook уже установлен, достаточно загрузить зависимости и открыть файл. В Colab необходимо распаковать **весь ZIP**, перейти в его папку и установить `requirements.txt`; одного ipynb без `src/`, `data/` и `outputs/` недостаточно. Установка PyTorch CPU в requirements рассчитана на Linux/Windows; для macOS нужна соответствующая сборка PyTorch без суффикса `+cpu`.

## Прогноз по сохранённой модели

```bash
python src/predict.py \
  --model outputs/models/LightGBM_unit_42.joblib \
  --input examples/new_listings.csv \
  --output outputs/demo_predictions.csv
```

Вход — исходные поля объявления: дата, числовые и категориальные характеристики из `RAW_INPUTS` в `src/core.py`. Поля истинной цены не требуются. Пример содержит три строки исходного набора без ценовых столбцов и предназначен для проверки интерфейса, а не для нового измерения качества. Если площадь отсутствует, используется медиана train; отсутствие ожидаемого столбца считается ошибкой схемы.

Файлы joblib нужно загружать только из доверенного источника. Сохранение и восстановление требуют совместимых версий scikit-learn, LightGBM и PyTorch. Для новых версий надёжнее переобучить модели.

Входной шум и повреждение обучающих цен разделены. Доли 5/10/20% означают количество выбранных строк, а не стандартное отклонение. Маски искажений одинаковы для всех моделей; при восстановлении полной цены модель P/A использует наблюдаемую, включая повреждённую, площадь. При ошибках обучающих цен validation остаётся чистой и правило остановки сохраняется.

Все диаграммы строятся из CSV. Сценарии ставки — диагностика реакции функции модели: их нельзя интерпретировать как причинное влияние кредитной политики. Важно также различать долю точных прогнозов и R².
